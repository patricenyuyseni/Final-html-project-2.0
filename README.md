Car Rental Website

A simple Car Rental website built using HTML and CSS, designed to showcase available cars for rent, booking options, and contact information. This project demonstrates responsive design, layout styling, and basic UI/UX principles.

 Features

Home Page: Display featured cars with images and brief descriptions.

Responsive Design: Works well on desktop, tablet, and mobile devices using CSS media queries.

Car Listings: Each car shows an image, model, price, and rental details.

Navigation Bar: Easy-to-use menu for navigating between sections.

Footer: Contact information, social media links, and other relevant details.

 Technologies Used

HTML5 – Structure of the web pages.

CSS3 – Styling, layouts, and responsive design.

Flexbox & Grid – Modern layout techniques.

Media Queries – Make the website mobile-friendly.
